# 0.5.4 — 알림 자동 닫기

성공/안내 배너는 4초, 오류 배너는 8초 뒤 자동으로 닫힌다. 같은 메시지가 다시 발생해도 타이머를 새로 시작하며 이전 타이머는 정리한다. 기존 수동 닫기 버튼을 유지했다. 연결 입력 또는 서버 지문 확인 창이 열린 동안에는 오류 타이머를 멈춰 내용을 읽고 수정할 수 있도록 했다. 확인 창 자체는 자동으로 닫지 않는다.

TypeScript/Vite 및 Tauri macOS 빌드: logs/polar-0.5.4-build.log. 브라우저의 미리보기 안내/오류를 이용해 표시 후 자동으로 제거되는 동작을 검증했다. 실제 사용자 인증이나 Vault 데이터는 변경하지 않았다.
