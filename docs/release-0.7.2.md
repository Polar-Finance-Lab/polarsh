# 0.7.2 — 빠른 전환 정리
- 빠른 전환의 ‘새 로컬 터미널’과 ‘폴더와 셸 선택’을 하나로 통합. ‘새 로컬 터미널’ 선택 시 폴더/로그인 셸 설정 화면을 연다. 설명: ‘폴더와 셸 선택 · ⌘ N’.
- 탭 옆 +와 ⌘ T는 기본 셸을 즉시 여는 동작 유지.
- 터미널 오른쪽 … 버튼 및 연결된 세션 도구바, 열림 상태 제거.
- 기존 도구바의 내부 호스트 연결/종료된 세션 다시 연결은 해당 세션에서 빠른 전환으로 접근 가능.
- TypeScript/Vite 및 macOS 앱 빌드 성공. 브라우저에서 통합 항목과 설정 화면 연결, 터미널 우측 버튼 제거 확인.
- 실행 중 사용자 세션은 재시작하지 않음.
