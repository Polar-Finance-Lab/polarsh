# 0.6.0 — 명시적인 SFTP 진입과 로컬/원격 파일 화면

## 사용자 흐름

SSH 탭 상단에 아이콘과 **SFTP** 텍스트 버튼을 표시한다. 연결 전/종료 후에는 비활성 상태와 안내를 제공하고, 로컬 터미널에는 표시하지 않는다. 기존 슬라이더 메뉴는 세션 메뉴(…)로 바꾸고, SFTP를 그 안에서 꺼냈다. 내부 호스트 연결 등 다른 도구는 유지한다.

SFTP 버튼을 누르면 기존 SSH 연결을 사용해 파일 화면을 연다. 왼쪽은 이 Mac, 오른쪽은 현재 SSH 서버다. 경로 직접 입력, 상위 폴더, 새로고침, 로컬 폴더 선택, 숨김 파일 표시를 지원한다. 일반 파일을 여러 개 선택한 뒤 가운데 업로드/다운로드 버튼으로 반대편의 현재 폴더에 전송한다. 전송할 경로는 시작 시 고정하며 전송 중에는 탐색을 잠근다. 선택은 전송 시작 시 해제해 실수로 같은 파일을 다시 보내지 않도록 했다.

아래에 진행률·완료·실패 및 개별 전송 취소를 표시한다. 원격 폴더 만들기를 유지하고, 터미널로 돌아가기 버튼으로 세션에 복귀한다. SSH 연결이 종료되면 터미널 화면으로 돌아간다. SFTP를 열기 위해 추가 인증을 요청하지 않는다.

## 구현 및 제한

`list_local_files`는 로컬 디렉터리 메타데이터만 읽는 명령이다. 기본 위치는 사용자 홈이며 Keychain/Vault에 접근하지 않는다. 디렉터리를 먼저 정렬하고 링크를 따라가지 않는다. 원격 파일 이름의 슬래시/NUL 항목은 제외해 다운로드 대상 경로를 벗어나지 않도록 한다.

기존 전송 엔진의 독점 생성 및 취소 시 부분 파일 정리 동작을 유지한다. 기존 파일을 덮어쓰지 않는다. 폴더 재귀 전송, 심볼릭 링크 전송, 파일 드래그 전송, 원격 파일 편집은 이번 범위에 포함하지 않았다. Termius의 코드/리소스는 사용하지 않았다.

## 검증

- Rust 파일 검사 4개 통과: 로컬 정렬·링크 처리, 파일/없는 경로 실패, OpenSSH SFTP 업로드·다운로드·덮어쓰기 방지, 취소 시 부분 파일 정리·디렉터리 작업. `logs/polar-0.6.0-files-tests.log`.
- 브라우저 실제 FilesPane + 메모리 전용 어댑터에서 다중 업로드, 다운로드, 취소, 이름 충돌 오류, 원격 폴더 생성, 900×620 및 1280×820 표시 확인. `app/qa-sftp.html`은 개발 전용이며 프로덕션 번들 진입점에 포함되지 않는다.
- 실제 SessionTabs에서 SSH 탭의 SFTP 텍스트 표시/미연결 비활성 상태 확인.
- TypeScript/Vite 및 macOS 번들 빌드: `logs/polar-0.6.0-build.log`. Rust Clippy: `logs/polar-0.6.0-clippy.log`.

사용자 실제 SSH 호스트나 자격증명으로 접속하지 않았다. UI 검증과 전송 엔진 검증은 별도로 수행했으며 네이티브 전체 전송 흐름은 사용자 서버로 재검증하지 않았다. 실행 중 앱은 종료하지 않았다.
