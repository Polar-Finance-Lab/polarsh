# 0.4.4 — 호스트 선택 모드와 저장 명령 자동완성

2026-10-24

## 호스트 선택

- 평상시 카드의 체크박스와 전체 선택 체크박스 제거.
- 검색줄의 '선택' 버튼으로 선택 모드 진입. 카드 전체가 키보드와 마우스로 누를 수 있는 토글 버튼이 된다.
- 선택은 테두리만 강조. 선택 모드에서는 연결/편집/즐겨찾기 버튼을 숨겨 잘못된 실행을 방지.
- 선택 개수, 전체 선택/해제, 그룹 이동, 삭제, 선택 완료를 검색줄 옆에 배치. 기존 큰 선택 작업 배너 제거.
- 삭제 확인 모달은 유지. 선택 완료/목록 이동 시 선택 상태를 초기화.
- 라이브러리 제목·도구줄·그리드가 세로로 압축되며 잘리는 문제 방지.

## 저장 명령

- 터미널 도구줄의 저장 명령 select 제거.
- 해당 터미널에서 `⌘J` 또는 하단 힌트 클릭 → 커서 근처에 저장 명령 검색 팝업.
- 이름/명령어로 필터링, 위아래로 선택, Enter 또는 Tab으로 삽입, Escape 또는 바깥 클릭으로 닫기.
- 검색어는 SSH/로컬 셸에 보내지 않는다. 일반 셸 입력과 Tab 자동완성은 가로채지 않는다.
- 한 줄 명령은 끝 개행을 제거한 뒤 삽입하며 실행 Enter를 추가하지 않는다. 이미 입력된 텍스트를 지우거나 대체하지 않고 커서 위치에 붙여넣는다.
- 여러 줄 명령은 기존 확인 모달을 거친다. 확인 후 붙여넣기는 셸 설정에 따라 실행될 수 있다는 기존 안내를 유지한다.
- 제어 문자 포함 명령 및 빈 명령은 거부. Vault가 닫혔거나 세션이 종료되면 자동완성을 닫는다.
- 로컬/SSH 양쪽 지원. 분할 화면에서는 키를 누른 패널의 세션을 대상으로 한다.
- 이번 버전은 명시적인 `⌘J` 호출 방식이다. 일반 명령줄을 감시하는 제안, 셸 파일 경로 자동완성, `;;` 입력 예약은 구현하지 않았다.

## 검증

- 실제 HostCard/SnippetCompletion을 사용하는 `qa-controls.html`의 격리된 표시용 데이터로 확인. 사용자 호스트와 SSH 연결은 변경하지 않음.
- 평상시 체크박스 없음, 선택 모드 카드 클릭 및 Space로 2개 선택, 테두리 강조 확인.
- 'docker' 입력 → 'docker ps -a' 결과, Tab 선택 콜백, Escape 닫기 확인. 이 검증은 UI 컴포넌트 검증이며 실제 SSH 실행 검증이 아니다.
- 명령 삽입 분류 회귀 테스트 4개 통과: 개행 없이 삽입, 여러 줄 확인, 제어 문자 차단, 빈 명령 거부/한글 유지. `logs/polar-0.4.4-tests.log`.
- TypeScript/Vite + macOS bundle 빌드 통과: `logs/polar-0.4.4-build.log`.
- 현재 실행 중인 이전 버전 세션은 강제로 종료하지 않았다. 네이티브 Cmd+J 및 실제 PTY 삽입의 최종 확인은 새 버전 재실행 후 필요하다.
