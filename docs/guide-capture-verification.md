# 네이티브 사용 가이드 촬영·검증 기록

촬영일: 2026-10-24 · 제품 버전: 1.0.0 · 테마: Frost

## 소스와 실행 환경

- 배포 기준: `v1.0.0`, 소스 커밋 `557969997e2bc4b17b0e106635ec6545dbd143ef`.
- `git diff v1.0.0 -- app/src app/src-tauri/src` 결과: 변경 없음.
- 실제 macOS Tauri 앱을 release 모드로 빌드하고 UI를 직접 조작했습니다.
- 촬영용 번들 이름: `Polarsh Guide`, 식별자: `dev.polarsh.guide.20261024`.
- 창 제목과 제품 UI는 Polarsh입니다. UI·SSH·SFTP·로컬 셸 코드는 배포 버전과 같습니다.
- 별도 식별자로 저장소와 Keychain 항목을 분리했습니다. 기존 `dev.harbor.ssh` 앱의 데이터는 사용하지 않았습니다.
- 빌드의 TypeScript 검사·Vite 번들·Rust release 컴파일 성공. 촬영용 앱의 ad-hoc 서명 검증 성공.
- 배포 ZIP과 `v1.0.0` 태그는 변경하지 않았습니다. 이번 변경은 문서와 이미지뿐입니다.

## 직접 확인한 동작

| 동작 | 실행·확인 결과 |
| --- | --- |
| 테마 | 네이티브 테마 창에서 Frost 선택 |
| 로컬 셸 | `/tmp`에서 실제 zsh 세션 생성, `pwd`, `printf`, `date` 실행 |
| 분할 | 새 로컬 영역 두 개 추가, 위쪽 크게 · 3분할 선택, 실제 배치와 구분선 확인 |
| 호스트 저장 | 별도 저장소에 실습 호스트 두 개와 그룹·태그·즐겨찾기 저장 |
| SSH | 루프백 서버에 비밀번호 인증으로 연결, 탭과 호스트 카드의 연결 상태 확인 |
| 지문 | 각 서버 프로세스의 출력과 앱 지문 표시를 대조 후 승인 |
| Bastion | 첫 서버의 direct-tcpip 채널로 두 번째 서버에 연결, 별도 SSH 세션 생성 |
| SFTP | 두 번째 서버에 Bastion 경유로 연결해 로컬 샘플 파일 두 개 업로드, 완료 상태와 파일 해시 확인 |
| 저장 명령 | `디스크 사용량` / `df -h` 저장, 실제 로컬 터미널에서 `⌘ J`로 선택 창 열기 |
| 빠른 전환 | `실습` 검색어로 열린 SSH 세션 검색 |

분할·SFTP 화면은 브라우저의 `qa-split.html`, `qa-sftp.html` 캡처가 아닙니다. 전송·인증 성공을 UI로 합성하지 않았습니다.

## 실습 서버 조건

저장소의 `app/src-tauri/examples/echo_fixture.rs` 실행 파일 두 개를 사용했습니다. 두 프로세스 모두 `127.0.0.1`에만 바인딩합니다.

| 역할 | 촬영 중 주소 | 서버에서 확인한 지문 |
| --- | --- | --- |
| Bastion | `127.0.0.1:53814` | `SHA256:ZO4ItdfwSOwBuMazNSycNNhFZ0UnjYGLwOx0PUXsi8o` |
| 내부 대상 | `inside.fixture.test:53815` | `SHA256:PB4irexGg6XjCAwh20588V7+0G8AdOBMLp4asPWdQ58` |

`inside.fixture.test`는 실습 서버가 loopback 대상으로 전달하도록 처리하는 테스트 이름입니다. 일반 DNS 주소가 아니며, 촬영 후 그대로 접속하는 공개 서버도 아닙니다. 계정은 실습 전용입니다. SSH 채널은 echo 방식이며 실제 원격 셸을 실행하지 않습니다. SFTP 서브시스템은 macOS의 `/usr/libexec/sftp-server`를 사용합니다.

## 업로드 검증

원본 폴더: `/private/tmp/polarsh-guide/local`  
대상 폴더: `/private/tmp/polarsh-guide/server`

서버가 같은 Mac에서 실행되지만, 전송 자체는 앱 → Bastion SSH 채널 → 대상 SSH/SFTP 연결을 통해 수행했습니다. 검증용 비교는 전송이 끝난 다음 로컬 파일 해시로 확인했습니다.

| 파일 | 원본·전송본에 공통으로 확인된 SHA-256 |
| --- | --- |
| `config.json` · 24 B | `a349fb3bf0e609b952ec8675b3219fcf573167ed1836febebbe57965fc397ebd` |
| `notes.txt` · 32 B | `6314c041216cfee38d441e464d3b27d18e3ba94dc9dafff1eed5d74943503689` |

이 확인은 가이드 촬영 시나리오 검증입니다. 외부 네트워크 환경·모든 SSH 서버 구현·전체 회귀 테스트를 검증했다는 의미는 아닙니다.

## 이미지 처리

12장 모두 실제 앱 창 전체를 캡처하고 PNG로 변환했습니다. 이미지 내용 교체, 버튼 추가·삭제, 연결 상태 합성, 테스트용 외곽 영역 잘라내기를 하지 않았습니다. 저장 크기는 1092×768px입니다. 화면에 보이는 배경 흐림은 앱의 대화상자 효과입니다.

호스트 입력과 테마 목록처럼 긴 영역은 앱 내부에서 스크롤됩니다. 등록 폼 상단을 보여주는 이미지에는 하단 연결 버튼이 보이지 않을 수 있으며, Bastion 이미지는 경로 영역으로 스크롤한 상태입니다. 본문에서도 스크롤 방법을 안내합니다.
