# 0.5.7 — 잠금 해제 화면 문구 정리

과거 인증 방식 변경을 설명하던 '추가 Touch ID' 문구와 재실행·업데이트 안내를 제거했다. 잠금 해제 화면에서 불필요한 세션 탭 전환 설명도 제거했다.

현재 화면에는 저장 호스트 접근에 필요한 Keychain 허용, 잠금 해제 유지 기간, SSH 비밀번호/키 암호 미저장 안내만 표시한다. 파일 덮어쓰기·데이터 이전 결과 등 실제 동작을 설명하는 문구는 유지했다. 인증과 저장 동작은 변경하지 않았다.
