# 0.5.2 — 터미널 홈 제거

별도 홈 화면, 상단 홈 버튼, 사이드바의 터미널 홈 메뉴와 소개 문구를 제거했다. 앱 실행 시 기존처럼 로컬 셸을 연다. 마지막 세션을 닫으면 로컬 터미널 열기 / 호스트 연결 두 동작이 있는 빈 화면을 표시한다. 앱 마크는 탐색 버튼이 아닌 장식으로 유지한다.

브라우저에서 홈 메뉴가 없고 빈 화면의 호스트 연결 버튼이 모든 호스트로 이동하는 것을 확인했다. TypeScript/Vite 및 Tauri macOS 번들을 빌드했다 (`logs/polar-0.5.2-build.log`). 기존 실행 중 앱은 종료하지 않았다. 실제 macOS PTY의 마지막 탭 닫기는 이번 UI 검증에서 실행하지 않았다.
