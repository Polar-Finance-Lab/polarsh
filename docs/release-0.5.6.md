# 0.5.6 — 새 탭 버튼 위치

탭 목록이 불필요하게 남는 폭을 채우지 않도록 변경했다. + 버튼은 마지막 탭 바로 오른쪽에 붙고, 배치·검색·호스트·도구 버튼은 오른쪽 끝을 유지한다. 탭이 많아지면 목록만 가로 스크롤되고 + 버튼은 계속 보인다.

브라우저 표시 검증: 탭 2개에서 마지막 탭과 + 버튼 사이 3px, 도구는 오른쪽 끝. 900px 창의 탭 8개에서도 목록은 가로 스크롤되고 추가 버튼과 도구가 겹치지 않음을 확인했다. TypeScript/Vite 및 macOS 앱 빌드: logs/polar-0.5.6-build.log.
