# 0.5.3 — 사이드바 통합 스크롤

왼쪽 전체 메뉴를 하나의 세로 스크롤 영역으로 변경했다. 열린 터미널 목록의 210px 높이 제한과 그룹 목록의 개별 스크롤을 제거했다. 그룹과 Vault 상태까지 자연스러운 높이로 이어지며, 창 높이가 부족하면 사이드바 전체가 스크롤된다. 터미널 모드의 오버레이 사이드바에도 동일하게 적용된다.

브라우저의 메모리 전용 호스트 12개/그룹 12개를 UI로 생성해 확인했다. 사이드바 높이 985px / 콘텐츠 높이 1074px, 그룹 목록 높이 512px이며 개별 overflow는 visible이다. 하단 버튼 접근 시 사이드바만 스크롤되고 그룹/문서 스크롤은 0을 유지했다. 사용자 Vault 데이터는 변경하지 않았다.

TypeScript/Vite와 macOS 앱 빌드 성공: logs/polar-0.5.3-build.log. 실행 중 앱은 종료하지 않았다.
