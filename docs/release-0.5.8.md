# 0.5.8 — 탐색 패널 버튼 중복 제거

호스트 화면에서 활동 막대 하단, 헤더, 세션 탭 줄에 중복될 수 있던 탐색 패널 버튼을 정리했다.

- 활동 막대 하단 버튼 제거.
- 호스트/빈 화면은 헤더 버튼 하나만 사용.
- 활성 터미널에서는 헤더가 숨겨지고 탭 줄 왼쪽 버튼 하나만 사용.
- 버튼 이름을 탐색 패널 펼치기/접기로 통일. 헤더에도 expanded 상태와 Cmd+B 힌트를 제공.

브라우저에서 패널 접기/펼치기 및 실제 SessionTabs 표시 fixture의 버튼 수를 확인했다. TypeScript/Vite 및 macOS 빌드: logs/polar-0.5.8-build.log.
