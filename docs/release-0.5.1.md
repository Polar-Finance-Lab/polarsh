# 0.5.1 — 저장 호스트 빠른 연결

빠른 전환에서 저장 호스트를 선택할 때 전체 편집 화면을 열던 경로를 분리했다. 호스트 카드의 연결과 재연결에도 같은 동작을 적용했다.

- 연결된 동일 호스트는 기존 세션 탭으로 이동한다.
- 비밀번호 방식은 호스트 식별 표시와 비밀번호 입력만 보여준다.
- SSH 키 방식은 저장된 키 경로로 즉시 연결을 시도한다. 키 인증 오류 시 암호 입력 화면에서 재시도할 수 있다.
- 상세 설정은 모든 호스트의 편집 버튼에서 변경한다.
- 연결 요청에 암호와 Bastion 세션 ID를 명시적으로 전달하여 이전 폼의 상태를 사용하는 문제를 방지한다.
- Bastion이 필요한 호스트는 활성 경유 세션이 없으면 안내하고 중단한다. 직접 연결로 우회하지 않는다.
- 최초 서버 지문 확인 및 변경된 키 차단은 유지한다. 인증 정보 저장 정책은 바꾸지 않았다.

검증: TypeScript/Vite와 Tauri macOS debug 빌드 성공 (`logs/polar-0.5.1-build.log`). 브라우저에서 표시용 호스트를 생성하고 빠른 전환→비밀번호 입력 전용 화면, 편집→전체 설정, 키 방식→상세창 없이 연결 진입을 확인했다. 브라우저는 IPC 연결을 하지 않으므로 실제 SSH 인증/암호화된 키 재시도는 이번 UI 검증에 포함하지 않았다. 실행 중 앱은 세션 보호를 위해 종료하지 않았다.
