## 촬영 범위

브라우저 미리보기, QA 컴포넌트 페이지, 합성된 터미널 출력을 사용하지 않았습니다. 1.0.0과 동일한 소스를 네이티브 앱으로 빌드해 UI로 직접 조작했습니다. 사용자 저장소와 분리하기 위해 앱 번들 이름·식별자만 촬영용으로 변경했으며 창 제목과 제품 UI는 Polarsh입니다.

캡처의 서버는 외부 운영 서버가 아니라 같은 Mac에서 실행한 테스트 SSH 프로세스 두 개입니다. 실제 SSH 인증·서버 지문 확인·Bastion 터널·SFTP 전송을 사용했습니다. 샘플 서버는 일반 원격 셸 대신 echo 방식으로 동작하며, 분할 이미지의 명령은 실제 로컬 zsh에서 실행했습니다.

앱 기본 테마나 테마 이름은 변경하지 않았습니다. 사용자의 기존 호스트·SSH 키·키체인 항목을 사용하지 않았고, 공개할 파일 목록은 촬영용 폴더로 한정했습니다.

## 다운로드 버튼 옆 안내 문구

> 첫 실행 시 Apple 확인 경고가 표시될 수 있습니다. 공식 배포 파일인지 확인한 뒤 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기로 실행하세요.

바로 아래에 **첫 실행 도움말** 링크를 붙이고 [macos-first-launch.md](macos-first-launch.md)로 연결하세요.

## 게시 전 확인

현재 GitHub 저장소와 릴리스는 비공개입니다. 공개 웹사이트에서 누구나 다운로드할 수 있다고 안내하려면 공개 배포 위치를 먼저 준비해야 합니다. 이번 작업에서는 저장소 공개 여부를 변경하지 않았습니다.

1.0.0 다운로드는 Apple Silicon Mac용입니다. Intel·Windows·Linux, Apple 공증, 동기화·협업을 지원한다고 안내하지 마세요. 지원 범위는 [사용 가이드](user-guide.md)를 기준으로 유지하세요.

이번 작업에서는 문서와 이미지를 준비했으며 웹사이트 자체는 배포하지 않았습니다.
