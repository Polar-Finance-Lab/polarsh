## 캡처 출처와 편집 범위

2026-10-24에 1.0.0 소스의 실제 React UI를 로컬 브라우저에서 조작해 캡처했습니다. 생성형 이미지나 디자인 목업은 사용하지 않았습니다. 사용자 호스트·SSH 키·키체인·실제 원격 파일에는 접근하지 않았습니다.

- `00`, `01`, `02`, `03`, `06`, `07`, `08`: 메인 앱의 브라우저 미리보기. 예시 호스트 3개와 그룹 2개를 UI로 입력했습니다. 미리보기 데이터는 메모리에만 보관됩니다.
- `04`: 기존 `qa-split.html`의 실제 탭·분할 컴포넌트. 예시 세션과 고정된 출력이며 실시간 SSH 연결이 아닙니다. 출력의 `DISPLAY FIXTURE / no live session` 표기를 유지했습니다.
- `05`: 기존 `qa-sftp.html`의 실제 파일 전송 컴포넌트와 메모리 기반 파일 목록. 업로드할 파일 두 개를 선택한 상태이며 실제 전송을 실행하지 않았습니다.
- 대화상자는 읽기 쉽게 주변 여백을 잘랐습니다. Bastion은 접속 경로 부분을 확대했습니다. 분할·SFTP는 개발용 외곽 영역을 제외했습니다. UI 내용이나 연결 상태를 합성하지 않았습니다.
- 사진의 주소는 `.test` 예시 주소이고 `/Users/fixture`는 예시 경로입니다. 브라우저 미리보기 안내 문구는 데스크톱 앱의 문구와 다릅니다.

게시할 때도 **“예시 데이터를 사용한 제품 UI 화면”**임을 밝혀 주세요. 이 이미지만으로 실제 SSH 접속·파일 전송 검증을 했다고 설명하지 마세요.

## 게시 전 확인

현재 GitHub 저장소와 릴리스는 비공개입니다. 공개 웹사이트에서 누구나 다운로드할 수 있다고 안내하려면 먼저 다운로드 파일을 공개된 배포 위치에 제공해야 합니다. 저장소 공개 여부는 이 문서 작업에서 변경하지 않았습니다.

1.0.0 다운로드는 **Apple Silicon Mac**용입니다. Intel·Windows·Linux, Apple 공증, 동기화·협업 기능을 지원하는 것으로 표시하지 마세요. 지원 범위와 설치 방법은 [사용 가이드](user-guide.md)를 기준으로 유지하세요.

이번 작업에서는 Markdown·이미지 자료를 준비했으며 웹사이트 자체를 배포하지 않았습니다.
