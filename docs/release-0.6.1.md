# 0.6.1 — 터미널 저장 명령 진입 수정

기존에는 Vault가 잠겼을 때 저장 명령을 열면 '먼저 작업 공간을 여세요'라는 오류만 표시했다. 이제 Cmd+J/저장 명령 버튼으로 터미널 안의 팝업을 열고, 명시적인 '키체인으로 저장 명령 열기' 버튼을 제공한다. 잠금 해제 성공 후 같은 팝업에서 명령 검색/삽입이 가능하다. 실패 시 오류를 표시하고 재시도할 수 있다. 팝업을 닫거나 다른 탭으로 이동해도 로컬/SSH 세션을 종료하지 않는다.

잠금 해제 상태에서는 Keychain을 다시 호출하지 않는다. 단순히 로컬 터미널이나 팝업을 열기만 해서는 인증을 요청하지 않는다. 명령 추가·관리 링크로 빈 목록에서도 다음 동작을 제공한다. 명령 선택은 삽입만 하며 자동 실행하지 않는다.

터미널 상단의 SSH 호스트 아이콘을 제거했다. 빠른 전환(Cmd+K)의 SSH 호스트 열기와 사이드바 탐색을 유지한다. SFTP 버튼은 별도 기능으로 유지한다.

검증: 시작/로컬 인증 경계 및 저장 명령 삽입 검사 6개 통과 (`logs/polar-0.6.1-tests.log`). 브라우저의 실제 SnippetCompletion 컴포넌트와 가상 잠금 해제로 잠금 안내→명령 검색→Tab 삽입 결과(executed:false)를 확인했다. 실제 Keychain 승인 UI는 자동 조작하지 않았다. TypeScript/Vite 및 macOS 빌드: `logs/polar-0.6.1-build.log`.
