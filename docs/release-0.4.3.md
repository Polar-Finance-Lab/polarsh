# 0.4.3 — 터미널을 기본 화면으로

2026-10-24

## 레이아웃

- 터미널 작업 중 상단 경로 표시줄, 왼쪽 고정 레일, 하단 버전 표시를 숨김.
- 한 줄 42px 탭 바에 탐색 패널, 홈, 세션 탭, 새 로컬 탭, 빠른 전환, SSH 호스트, 도구 토글 배치.
- 세션 탭이 많으면 탭 부분만 가로 스크롤. 새 탭/검색/도구는 고정. 활성 탭을 자동으로 보이는 범위로 이동.
- 탐색 패널은 필요할 때 터미널 위에 겹쳐 표시. 셸의 열 수와 줄바꿈을 바꾸지 않음. 패널 밖 클릭 또는 토글 버튼으로 닫기.
- 도구줄은 기본 접힘. 파일, 분할, 저장 명령, 세션 설정은 오른쪽 도구 토글로 열기.
- 새 로컬/SSH 세션에서는 패널과 도구줄을 접음. 호스트/라이브러리 화면은 기존 탐색 구조 유지.
- 패널/검색/설정 등을 닫고 터미널로 돌아오면 터미널 입력 포커스 복원. 다른 모달이 열려 있으면 포커스를 가져오지 않음.
- 새로운 이미지/아이콘/브랜드명 변경 없음. 인증 및 SSH 엔진 변경 없음.

## 화면 검증

실제 `SessionTabs`와 `TerminalPane`를 사용하는 개발 전용 `qa-split.html`에서 측정. 테스트 세션은 실제 SSH/PTY에 연결되지 않은 표시용이며 운영 번들 진입점이 아니다.

| 앱 내부 크기 | 기본 터미널 영역 | 면적 비율 |
| --- | --- | --- |
| 1280 × 820 | 1256 × 760 | 90.95% |
| 900 × 620 | 876 × 560 | 87.91% |

OS 제목 표시줄은 위 면적에 포함하지 않음. 오류 배너, 열린 패널, 도구줄, 분할 제목줄이 있으면 가용 면적이 줄어듦.

- 8개 세션에서 마지막 탭 선택 시 가로 스크롤 확인.
- 900 × 620에서 도구 펼침/접힘, 분할/분할 해제 확인. 분할 패널 각각 431 × 520, 겹침 없음.
- 탐색 패널 표시/닫기 확인.
- TypeScript/Vite 및 macOS bundle 빌드 통과: `logs/polar-0.4.3-build.log`.
- 실행 중인 0.4.2 프로세스의 세션은 강제 종료하지 않음. 0.4.3 네이티브 화면은 앱 재실행 후 확인해야 함.
