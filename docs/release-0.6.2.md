# 0.6.2 — 화면을 밀지 않는 상단 알림

전역 오류/안내 배너를 앱 상단 중앙의 고정 토스트로 변경했다. 나타날 때 위에서 아래로 200ms 이동하며 표시한다. 모달보다 위에 표시되며, 알림 이외의 영역은 클릭을 가로채지 않는다. 동작 줄이기 설정에서는 애니메이션을 생략한다.

Keychain 오류를 포함한 전역 오류는 터미널·연결 폼의 공간을 차지하지 않는다. 연결/지문 확인 폼에 중복 표시하던 전역 오류와 저장 명령 팝업에 전달하던 오류도 제거했다. 기존 자동 닫기 시간 및 확인 폼 중 타이머 일시 정지 정책, 수동 닫기를 유지한다. SFTP의 개별 경로 오류/전송 결과는 해당 화면의 상태로 유지한다. macOS 알림 권한은 추가하지 않았다.

브라우저에서 알림 전후 작업 영역 좌표/크기가 x230 y48 / 1480×905로 동일한 것을 확인했다. fixed 위치, 진입 애니메이션, 수동 닫기도 확인했다. TypeScript/Vite 및 macOS 빌드 성공: logs/polar-0.6.2-build.log.
