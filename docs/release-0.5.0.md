# Polar Terminal 0.5.0 — 탭 드래그와 다중 분할

2026-10-24. 로컬/SSH 터미널 모두 같은 분할 UI를 사용한다.

## 사용 방법

- 상단 탭을 터미널 영역의 왼쪽·오른쪽·위·아래로 끌면 해당 위치에 배치된다. 드래그 중 배치 미리보기를 표시한다. Esc로 취소한다.
- 상단 오른쪽의 **터미널 배치**에서 단일 화면, 좌우/상하 2분할, 왼쪽/위쪽 크게 3분할, 격자 4분할을 선택한다. 필요한 수만큼 탭을 먼저 열어야 한다.
- 최대 4개 영역. 기존 영역을 다른 위치로 옮길 수 있으며 같은 세션을 중복 표시하지 않는다.
- 영역마다 번호, LOCAL/SSH, 세션 이름, 주소/시작 폴더를 표시한다. 활성 영역은 밝은 테두리와 제목 배경으로 구분한다.
- 영역의 확대 버튼으로 하나에 집중하고, 복원 버튼으로 원래 배치로 돌아온다. 확대 중에는 드롭을 받지 않는다.
- 영역의 ×는 **분할에서 빼기**다. 세션은 열린 탭에 유지된다. 상단 탭의 ×는 기존 세션 종료 동작이다.
- 이미 보이는 탭을 클릭하면 활성 영역만 바뀐다. 다른 탭을 선택하면 현재 활성 영역을 대체하고 나머지 배치는 유지한다.

## 구현

`pane-layout.ts`의 이진 분할 트리가 위치를 계산한다. `TerminalDeck`은 세션별 React key와 xterm 인스턴스를 유지하면서 위치/크기만 바꾼다. 레이아웃 변경은 연결/해제 명령을 호출하지 않는다. 기존 ResizeObserver가 PTY 크기 변경을 전달한다.

`useTabDrag`는 Pointer Events를 사용한다. 7px 이동 후 드래그로 판단하고, 드롭 직후 발생하는 클릭을 억제한다. 마우스 이외에도 배치 메뉴 버튼으로 프리셋을 선택할 수 있다.

## 검증

- 레이아웃/저장 명령 회귀 테스트 11개 통과: `logs/polar-0.5.0-layout-tests.log`.
- TypeScript/Vite 및 Tauri macOS debug 번들 빌드 성공: `logs/polar-0.5.0-build.log`.
- 번들 Info.plist 버전 0.5.0 확인, 크기 50.05 MiB.
- 실제 컴포넌트를 사용하는 개발 전용 `qa-split.html`에서 브라우저 포인터로 탭을 끌어 1→2→3→4분할 확인.
- 상하 2분할, 위쪽 크게 3분할, 격자 4분할, 확대/복원, 영역 제거 후 탭 유지, 기존 영역 재배치, 5번째 영역 차단, 활성 탭 전환 후 4영역 유지 확인.
- 1280×820: 4분할 각 영역 626×377px. 900×620: 각 영역 436×277px. 영역 중첩 없이 표시됨. 숨긴 탭 포함 8개 터미널의 출력 내용 유지 확인.

위 UI 검증은 IPC 없는 표시용 세션으로 수행했다. 이번 변경에서 실제 SSH 서버 접속이나 macOS WebView의 드래그 동작을 재검증하지 않았다. 실행 중이던 앱은 작업 중인 세션을 보존하기 위해 종료하지 않았다. 최신 번들을 사용하려면 앱을 완전히 종료한 후 다시 실행한다.

## 남은 범위

현재 배치는 균등 이분할 기반이다. 분할 경계 드래그로 비율 조절, 배치 저장/복원, 여러 창 사이 탭 이동은 후속 범위다. SSH/Keychain 인증 동작은 이번 변경 대상이 아니다.
