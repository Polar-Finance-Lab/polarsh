# Polarsh 1.1.0

저장 명령을 찾는 창을 따로 열지 않고, 터미널에 입력한 내용으로 제안받을 수 있습니다.

- `df -h`를 저장한 상태에서 `df`를 입력하면 제안합니다.
- Tab은 첫 제안의 남은 부분을 삽입합니다. 다른 제안은 클릭해 삽입합니다.
- 실행은 직접 Enter를 눌러야 합니다. Escape로 닫습니다.
- 저장소 잠금 해제 상태에서만 동작하며 자동 인증 요청은 하지 않습니다.
- 로컬·SSH 세션에 적용합니다. 분할 화면에서는 포커스가 있는 터미널에만 제안합니다.
- 최대 5개를 표시하고 같은 명령은 하나만 보여줍니다.
- 여러 줄 명령과 터미널 제어 문자가 있는 명령은 자동 제안하지 않습니다.

## 범위

일반 프롬프트의 한 줄 끝을 화면에서 확인하는 방식입니다. 셸의 전체 문법이나 실행 중인 프로그램을 해석하는 기능은 아닙니다.
일부 사용자 지정 프롬프트, 줄바꿈, 커서 중간 편집, 전체 화면 프로그램에서는 제안하지 않습니다.
기존 ⌘ J 수동 검색은 유지합니다. 제안을 위해 입력 내용을 별도 기록하거나 외부 추천 서비스에 전송하지 않습니다.

## 검증

- TypeScript 로직 테스트 69개와 React 컴포넌트 통합 테스트 1개 통과.
- Rust 테스트 35개 통과, 명시적 환경 의존 테스트 4개는 기존대로 제외.
- 프런트엔드 프로덕션 빌드와 macOS ARM64 앱 빌드 완료.
- 번들 ad-hoc 서명 후 `codesign --verify --deep --strict` 통과.
- 컴포넌트 테스트는 가상 DOM과 터미널 이벤트 대역을 사용합니다. 실제 SSH 서버에서의 자동 제안 화면 검증과는 구분합니다.
