# 0.7.1 — 저장된 호스트와 터미널 배치 개선

## 변경
- SSH Vault 열기 등 주요 탐색 버튼을 ‘저장된 호스트 열기’로 정리.
- 사이드바에서 중복된 ‘폴더와 셸 선택’ 바로가기 제거. 세션 메뉴의 고급 로컬 열기 기능은 유지.
- +로 새 로컬 탭을 열거나 SSH를 연결하면 현재 영역만 전환하고 다른 분할 영역과 비율을 유지. 이전 세션은 탭에 남는다.
- 배치 메뉴에 ‘오른쪽에 새 터미널’, ‘아래에 새 터미널’ 추가. 기본 셸을 새 세션으로 열고 활성 영역을 분할한다. 최대 4개 영역.
- 좌우/상하 분할 경계에 10px 드래그 영역과 손잡이를 추가. 중첩된 3·4분할 경계도 각각 조절.
- 경계 더블클릭 또는 키보드 Home/Enter로 해당 경계 균등 분할. 방향키 2%, Shift+방향키 10% 조절. 드래그 중 Esc는 시작 비율로 복원.
- 최소 영역 기준 너비 180px, 높이 110px. 화면 자체가 최소 크기 합보다 작으면 비례 배분.
- 터미널 인스턴스는 그대로 유지하며 기존 ResizeObserver가 xterm 및 연결된 PTY 크기를 갱신한다.
- 비율은 현재 실행 중 레이아웃에 유지된다. 앱 재실행 시 세션/비율 복원은 이번 변경 범위가 아니다.

## 검증
- pane-layout 및 local-auth-boundary 16개 테스트 통과: 중첩 비율, 새 탭 비율 보존, 최소 크기 제약, 기존 도킹, 로컬 열기 인증 경계.
- TypeScript/Vite 및 macOS Tauri 디버그 앱 빌드 성공.
- 브라우저 표시 fixture: 4분할 위쪽 너비 경계 드래그 50% → 67%, 아래쪽 경계는 50% 유지.
- 새 터미널 오른쪽/아래 추가 버튼으로 3분할 생성 확인.
- 3분할 오른쪽 높이 경계 드래그 50% → 65%, Home으로 50% 복원 확인.
- 표시 fixture는 실제 SSH/PTY 연결을 수행하지 않는다. 이번 변경의 macOS 네이티브 포인터/실서버 리사이즈는 별도 실행 검증하지 않았다.
- 실행 중 사용자 터미널은 종료하거나 재시작하지 않았다.
