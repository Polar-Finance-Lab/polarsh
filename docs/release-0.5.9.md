# 0.5.9 — 드래그 분할 미리보기 보강

드래그 도중 포인터 위치의 DOM 요소를 찾던 방식 대신, 표시된 터미널 영역의 사각형 좌표로 드롭 위치를 판정한다. 영역 사이/바깥쪽의 좁은 여백도 포함한다. 포인터 이동과 놓기 이벤트를 capture 단계에서 받고, 드래그 중 터미널 내부의 포인터 입력을 막으며 탭의 브라우저 기본 드래그를 방지했다.

미리보기는 dockPane으로 계산한 최종 배치의 실제 사각형을 표시한다. 기존 영역을 옮겨 원래 자리가 합쳐지는 경우에도 최종 크기를 사용한다. 강조 테두리와 '놓아서 적용' 문구를 표시한다. 단일 세션을 자기 자신에게 드래그하면 복제하지 않고 다른 탭을 끌라는 안내를 표시한다. 최대 4영역 제한 및 확대 중 분할 금지는 유지한다.

검증:
- 배치 단위 검사 7개 통과: logs/polar-0.5.9-layout-tests.log.
- 브라우저 실제 포인터 드래그로 우측 분할 및 아래 여백으로 드롭한 상하 분할 확인.
- QA 화면에서 드롭 직전 미리보기 DOM의 좌표를 기록해 실제 결과와 비교. 우측 미리보기 626×760px, 상하 미리보기 1258×377px로 결과 일치.
- TypeScript/Vite와 macOS 빌드 성공: logs/polar-0.5.9-build.log.

macOS WebView에서 사용자가 경험한 실패 원인은 직접 재현하지 못했다. 사용 중인 네이티브 앱은 세션 보호를 위해 종료하지 않았으며, 이번 드래그 검증은 브라우저의 실제 컴포넌트 표시 fixture에서 수행했다.
